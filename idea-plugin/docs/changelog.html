0.7.1 — 本地迭代（2026-10-10，未发布）

新增

  • 内置使用指南：五张 IDEA 实拍截图、操作入口、预期结果与检测边界，离线可查看。
  • Tools → FlutterGuard: Usage Guide & Changelog；设置页直接查看场景与版本记录。

修复

  • 修复内置说明页的离线图片加载、HTML 渲染与窄窗口图文布局。
  • 生命周期检查识别 nullable / 泛型资源字段，以及同一声明中的多个字段。
  • 改用 AST 识别释放调用，避免把字符串当成 cleanup；支持 dispose 直接调用本类 helper。
  • 只显示当前文件的 findings，拒绝无效行号与过期文档结果；未保存文件提示保存。
  • 进程输出在执行期间读取；超时、配置错误、无效报告不再表现为零问题。
  • Windows native CLI 资源名包含 .exe；同一 IDE 进程复用提取的 CLI。

调整

  • IDE 展示 severity，不执行 CI severity gate；业务契约由消费项目维护。

  • 插件说明、离线指南与标准 change-notes 明确区分静态检查、扫描失败和实际验收。
