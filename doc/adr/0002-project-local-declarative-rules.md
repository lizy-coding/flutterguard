# 以项目本地声明式约束扩展通用检测基础

状态：长期方向保留，首版暂缓（2026-10-16）。首版执行范围以 ADR-0003 为准。

BoundaryLens 的通用范围先限定不同业务的 Dart/Flutter 项目，用户在项目仓库内维护
有限声明式规则，复用产品提供的事实和检查能力；不要求用户编写任意 Dart/脚本，
本阶段也不建设组织规则包或公开规则市场。

后续访谈中用户进一步收敛：首版不交付自定义规则，只满足内部扩展性和基础结构。
因此本文不再作为首版自定义功能的实施授权；原文保留为取舍记录。

相比仅开放内置参数，这允许项目表达自己的约束；相比可执行扩展，它降低了接入、
权限与兼容维护负担，并避免仅重复官方 analyzer plugin 的规则开发入口。
模块公开入口保护继续作为首个已实现能力和验收基线，本决定不宣称已支持任意自定义检测。

CLI 继续拥有检测，IDE 继续展示同一结果。声明式定义与既有单一注册表如何统一、
规则身份、测试、覆盖状态及输出兼容在下一轮决定；不先增加第二规则注册体系。
